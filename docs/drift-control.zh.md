# 漂移控制

长周期工作有两种失败方式：停下来，或者继续朝错误方向走。停下来容易发现——台账不再增长。漂移代价高，
因为每一步看起来都合规。本文列出我们预期会发生的失败、捕获它的信号，以及阻止它的机制。没有执行点的
机制只是愿望，所以每一行都写明它在哪被执行。

## 执行点

| 执行点 | 是什么 |
|---|---|
| Gate（闸门） | `plan.md` 里声明的确定性命令。 |
| Validator（校验器） | `scripts/validate-mission.mjs`，由闸门运行。 |
| Ledger（台账） | 只追加的事件；唯一的真相。 |
| Review（评审） | milestone 时全新上下文的评审者。 |
| Human（人类） | milestone 检查点；唯一有权改变目标的角色。 |
| Policy（策略） | 预算、命令白名单、停止条件。 |

## 失败模式

| # | 失败 | 早期信号 | 机制 | 执行点 |
|---|---|---|---|---|
| 1 | 目标被静默改写 | 目标哈希变化但没有修订事件 | 目标冻结 + `mission_amended` | 校验器 + 审计 |
| 2 | 任务与目标无关 | 任务没有 `serves` | 验收可追溯 | 校验器（`T-002`） |
| 3 | 计划扩大范围 | 任务无法追溯到验收标准 | 修订必须引用验收标准 | 审计 + 人类 |
| 4 | 闸门不可能失败 | 闸门永远不会退出非零 | 一个必须被拒绝的 fixture | `T-003` |
| 5 | 闸门被削弱 | 通过修订降低 severity 或命令强度 | 修订要说明它仍证明什么；旧证据保留 | 审计 |
| 6 | 实现者自我认证 | 实现者自己写 `task_done` | 控制器调用 verify/record；适配器只交报告 | 协议 + `T-002` |
| 7 | 台账与代码分叉 | 有提交无事件，或有事件无提交 | `reconcile` | `T-002`、`T-005` |
| 8 | verify 与 record 之间崩溃 | 过期证据、无事件或重复提交 | 台账即状态；`reconcile` | `T-002`、`T-005` |
| 9 | 新会话误读状态 | frontmatter 与台账不一致 | 从台账推导状态 | `T-002` |
| 10 | 决定随上下文丢失 | 推理只存在于对话里 | ruling、note、inbox 文件 | 协议 |
| 11 | tick 内范围蔓延 | diff 里出现计划外文件 | 一 tick 一任务；声明文件 | AGENTS + 评审 |
| 12 | 预算烧穿 | 3 次尝试、2 轮修复、2 小时 | 停住，不要即兴发挥 | 策略 |
| 13 | 工具链或平台失败 | 闸门跑不起来；路径或行尾不匹配 | 固定白名单；`.gitattributes`；大声失败 | 策略 + 仓库 |
| 14 | 被包或 harness 锁死 | 某个技能带来自己的台账或状态 | 适配器边界；单一台账 | 决策 0002 |
| 15 | 评审疲劳 | milestone 审计被跳过 | 固定节奏；人类检查点 | 策略 |

## Milestone 审计

每完成三个任务之后、以及 mission 结束时，在开始下一个任务之前运行。结论记为 `review_result`；
`fail` 让 mission 停住。

1. **覆盖。** 已完成的工作推进了哪些验收标准？哪些仍未证明？引用任务和它的证据。
2. **非目标。** 是否有任务碰了非目标？引用任务和允许它的 ruling。
3. **冷启动。** 一个全新会话，只拿到仓库，说出下一个任务、它的闸门，以及它为什么服务 mission。
   答错就是漂移，即使所有闸门都是绿的。

## 修订

修改 `mission.md`、`policy.md`、`plan.md` 或 `docs/protocol.md` 需要 `mission_amended` 事件：

- `old` 和 `new`：每个被修改产物的 path → sha256；
- `acceptance`：这次修改服务的验收标准；
- `why`：原因；
- `approved_by`：目标、非目标、验收或协议变更填 `human`；在既有验收范围内修改计划填 `cairn`。

在 `T-002` 实现该事件之前，修订记录为携带同样字段的 `ruling`。不允许静默修改。

## 这套机制保证不了什么

- 它无法发现一个从一开始就错误的目标。那是人类检查点的职责。
- 它无法替代 milestone 时的人类判断；它只能让“跳过”变得可见。
- 它无法让一个闸门证明它没有度量的东西。
